Just a simple app to take "big render" images from Mandelbulb3D and stitch them together.

Installation:
Download latest from "Releases" folder and setup

Use:
1. Run the program
2. Use the folder button to select the directory where the tile images were rendered (usually under your "Parameters" directory). It should populate the information automatically. 
3. Change the name of the image if you wish, or just take the default.
4. Press "Go"

It should write the file out to the same directory where the tile images are located.
